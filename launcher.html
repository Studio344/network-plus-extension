Network+

Set up live recording

  1. Open DevTools in this tab

    Mac
    ⌘ Command + ⌥ Option + I
    Windows / Linux
    Ctrl + Shift + I

  2. Select the Network+ tab

    If it is hidden, look under » or the + button (More tools) in DevTools.

  3. Open a bookmark in this tab

    Keep DevTools open and go to the site you want to record from your bookmarks or favorites.
