Network+

Set up live recording

Select Network+ before visiting a site to capture its very first request.

  1. 1

    Open DevTools in this tab

    Mac
    ⌘ Command + ⌥ Option + I
    Windows / Linux
    Ctrl + Shift + I
  2. 2

    Select the Network+ tab

    If it is hidden, look under » or the + button (More tools) in DevTools.

  3. 3

    Open the site in this tab

    Keep DevTools open and navigate to the site you want to record, for example from a bookmark.
